# P04 Window 供值领域与 Native leaf 分段校验

本波次保留四个准确已准入 Window 与四个 collection transform 的实际供值身份；公开 Variant identity CAST 只保留独立原声明。FE 按原 provider ordinal 借用准确 Variant 声明并核实际 carrier/tree，普通 Binary 不猜成 Variant，固定 Binary 不猜成 LargeInt。Sort/Redistribute 透传保留实际字段 owner，最终结果适配器发布准确名称与领域，并继续拒绝实际冲突。

Native leaf 构造不扫描完整 timezone；三份不可变来源按 turn 校验，完成私有 witness 后才允许输出。每 turn examined ≤64KiB、work ≤1024。实际 allocator 探针确认 cursor Box 与单列 Vec 在原 scratch credit 返回前物理退出。原 source/metadata-container、RootInputPermit 和通知 callback 全图未由此探针证明；初始 whole-wrapper drop 失败中已有 callback 分配两块共128B，修正后的测量范围明确保留这个限制。

最终12个 product/test pins、8项有效 compiled runtime 源码反例、恢复后的 Cargo-only 全量及最终 binary 上8个 SQL cases和独立1FE+3BE baseline见 manifest。全量12236PASS/7ignored、593s。保留原失败和一次无效变异探针：首实际 Variant Analyze 身份丢失、Sort 声明/实际 schema 漂移、测试误用未准入函数、新测试编译借用错误、sortby内外 Cast marker 断言错误。用例保留原 CAST/window/typed-null 表达式，以既有 Variant accessor 观察数值，避免假称 legacy row API 已有 Scalar JSON 呈现；golden没有从候选录制。

此前记录的 binary pins仅绑定 provider 修复后、Sort 修复前的失败运行；最终通过绑定 native-binary-pins-final.json，不能把初期 binary 写成最终产物。

这不是完整 Scalar producer、所有 builtin/lambda、source growth 或 Host 安装验收。V1未发布，P04 executing，P05–P10 open；DNS与nested scalar计量仍待裁决。无完整SQL/default System、Linux/release性能或整个M07完成结论；Linux由用户手测。无push、PR或archive。System只保存显式safe allowlist，未复制配置、JWT或完整diagnostics。较大日志用lossless gzip保存。
